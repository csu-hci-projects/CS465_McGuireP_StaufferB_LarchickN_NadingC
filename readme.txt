Instructions on how to use app:
Uses Unreal Engine 5.5

A/B and Y/X open the task list
You can point with the non-menu hand and squeeze the pointing hand trigger to select an item.
You can also look at an item in the task list and squeeze the non menu hand trigger to select an item.

Teleport works by pressing and holding the thumbstick forward on either controller.
Release the thumbstick/trackpad to teleport to the selected location.
